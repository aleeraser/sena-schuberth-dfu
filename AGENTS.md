# SCHUBERTH Bluetooth Device Manager — Linux reconstruction

Reverse-engineering workspace for the SCHUBERTH Bluetooth Device Manager
(firmware updater for SCHUBERTH motorcycle headsets). The vendor ships only
Windows and macOS installers; the goal of this repo is to understand those
apps and build a Linux equivalent.
